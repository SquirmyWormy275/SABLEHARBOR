# Blackridge Public/Private Data Boundary

The public repository contains schemas, deterministic public generators, participant-safe data,
workbooks, validation, and manifests. It must never contain oracle tables, answer keys, hidden
component health, exact hidden provenance, evaluator scoring, or causal truth. Private generation
is intentionally not published here. The private companion exists at
`SquirmyWormy275/SABLEHARBOR-ORACLE` with private release `blackridge-oracle-v0.1.0`. Public metadata
records its existence without copying hidden truth. A fingerprint scan of the public working tree,
all reachable revisions, public workbook, and public schema found no restricted oracle payload.
