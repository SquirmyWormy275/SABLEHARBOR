# Blackridge Public/Private Data Boundary

The public repository contains schemas, deterministic public generators, participant-safe data,
workbooks, validation, and manifests. It must never contain oracle tables, answer keys, hidden
component health, exact hidden provenance, evaluator scoring, or causal truth. Private generation
is intentionally not published here. Until a private companion release is established, that gate
remains blocked rather than being simulated with a public placeholder.
