# Blackridge Provisional Accounting Policies

The case uses USD minor units, calendar-month periods, double-entry journals, straight-line
depreciation for the current foundation, transaction-derived statements, and a discounted-cash-
flow recoverable amount for Phase 4. These synthetic policies are coherent case assumptions and
are not authoritative GAAP guidance. The impairment equals carrying amount less recoverable
amount and is posted only after that calculation.
