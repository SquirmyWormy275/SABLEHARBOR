# Limitations and Open Decisions

- The detailed domain schema is broad but several low-volume domains remain foundation-level.
- The workbook exposes all mandated navigation surfaces, but many high-volume sheets redirect to
  SQL rather than embedding full raw facts.
- PostgreSQL execution and external specialist review remain open.
- Cutoff databases, all mandated corruption mutations, rendered workbook previews, and the private
  oracle repository/release have been materialized and validated.
- Acceptance states must not be promoted beyond the evidence generated by this build.
