# Blackridge Maintenance Model

Assets, serialized components, notifications, work orders, downtime, condition observations,
backlog, repairable pools, and labor bookings share stable identities and time fields. The full
profile includes 3,000 assets, 1,600 serialized components, 6,200 work orders, and 30,500 labor
bookings. Component exclusivity and resource-prerequisite mutation tests remain to be deepened.
