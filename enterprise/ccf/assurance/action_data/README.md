# Actionable procedure authoring

SABLEHARBOR owns this implementation. Atlas remains a read-only reference guide.

- `baseline_checks.json` adds 116 targeted source-condition and procedure/test checks to the prior section-only baseline entries. HIPAA role, legal-process and context checks are assessment work, not 83 invented recurring safeguards. The checks are not exhaustive paragraph/exception decompositions.
- `source_gates.json` supplies three concrete context/amendment analyses. The 27001 climate amendment has an executable proposed context-review procedure; actual relevance remains management's decision. Full ISO27000:2026 and ISO22989:2022 reference reconciliation, and full AI Annex B interpretation, remain explicit dependencies. Publisher records were checked on 2026-09-12; no reference overview substitutes for full content.
- `finding_actions.json` integrates the 50 existing corrective findings into proposed procedures or assessment work. Eight capability candidates identify concrete conditional product/architecture work; none asserts that the capability is absent, funded or deployed.
- `c5_child_checks.json` contains 623 individually authored comparisons/test directions against the retained publisher child criteria and the 86 draft procedures. Each has an explicit proposed native route and work classification. These are engineering first-pass comparisons, not approved mappings. Compound duties, full linked parent guidance, permitted alternatives and actual customer/provider responsibilities still require reconciliation and independent review. Additional-complement criteria are provider criteria; corresponding customer responsibilities remain separate.
- `author_bindings.json` pins this author iteration to the previous source/design analysis and the new records. Builds reject changed author inputs. Reconsideration and explicit author binding are required for revisions; no automatic approval or rebinding command exists.

The generated library keeps the original procedure and source-linked proposed additions together. Reuse means a candidate needing validation. Enhancements include procedure and evidence-test detail. New capability candidates require selected/applicable criteria and actual capability assessment before becoming implementation work. Assessment-only records do not inflate the operating-control delta count.

The CLI selects whole framework planning extensions. It does not decide whether every C5 additional criterion applies. Each C5 action retains its publisher kind and selection dependency, including the conditional more-than-two-location requirement. The approved Reno/Boise reference is unchanged.

Original documents and generated reports remain in local source holdings/ignored SABLEHARBOR output. The tracked records contain authored comparisons and fingerprints, not reproduced standards.
