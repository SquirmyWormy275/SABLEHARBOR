# Source comparison authoring records

- `findings.json`: 50 author findings with source locators, decomposed duties, observed draft-design gaps, corrective procedures, tests and outstanding decisions.
- `iso_condition_checks.json`: 193 source-objective checks. They complement rather than replace exact clause, exception and Annex B review.
- `c5_domain_review.json`: 17 domain-level comparisons from the retained publisher criteria. Candidate domain routes are proposals, not mappings entered into the assessment engine.
- `addressable_specifications.json`: the 22 HIPAA addressable specification identifiers and source labels; source paragraphs resolve uniquely during build.
- `finding_bindings.json`: persisted fingerprints of reviewed sources, catalogue, draft designs and author analysis. Build rejects changes; regeneration is an author reconsideration step, not automatic approval.
- `REVIEW_NOTES.md`: reviewed scope, explicit limitations, source dependencies and owner/reviewer decisions.

Original regulatory/standard text is retained in local source holdings, not reproduced here. Source line fingerprints help navigation; they do not themselves prove atomic normative decomposition or semantic agreement. All substantive independent approvals and actual implementations remain unasserted.
