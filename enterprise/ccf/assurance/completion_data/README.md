# Control-library completion authoring

These are original proposed SABLEHARBOR operating procedures, not reproduced standard text or independently accepted compliance mappings.

- `control_procedures.json` supplies the 22 selected extension candidates without a baseline procedure. Each has an operating procedure, evidence outputs, independent test and actual inputs needed.
- `additional_measures.json` supplies 11 known technical design additions linked to existing ISO requirement locators. Links are candidate design routes, not accepted equivalence or a complete gap inventory.
- `DECISIONS.md` consolidates business facts and authorities required for actual operation and review. It preserves the approved reference scenario without inventing deployments or appointments.

The completion builder joins these with existing baseline designs and the source-bound framework inventory. Native control statements remain unchanged. Source conditions, design sufficiency and further measures remain open workpaper fields until substantive review; the packet's availability must never be presented as finished coverage review.
