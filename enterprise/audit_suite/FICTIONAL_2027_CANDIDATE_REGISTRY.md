# Partial fictional 2027 source-routing diagnostic

`fictional_2027_candidate_registry` re-verifies the ten independently reviewed
company-native 2027 cohorts (178 versions) and combines their exact physical
source routes with the frozen 13-component A/B technical baseline. It writes
private, loadable `FederatedCompanyStore` profiles for Clean and Messy. The
candidate has 23 components and 145 system aliases on each side. These profiles
are diagnostic routing inputs only; the active audit pair and its source binding
remain unchanged.

The logical profile company is `SABLEHARBOR`. Physical sources retain their
original `SABLE-HARBOR-REFERENCE`, `SABLEHARBOR`, or `SH` identifiers and their
branch-specific Clean/Messy identities. A/B here denote two routing profiles,
not new engagements. This mixed identity is explicit in the report and cannot
prove a coherent operating year. The module pins each original review, receipt,
database and frozen base registry; checks sidecars, SQLite integrity and branch
isolation; then loads the generated profiles through the production federation
adapter. It creates no grants, collections, source mutations or task credit.

The output sets `source_complete=false`. The 283 discovery routes per side still
need source/authorized-nonoccurrence/gap disposition, population completeness,
qualified authority, a separately reviewed final registry and a fresh
zero-evidence pair before any ordinary PBC collection. Future 2027 events are
fictional as of September 29, 2026; this is not real company operation or an
external assessment. Atlas remains a read-only reference.
