# Local access-remediation continuation

`company_access_remediation_activity.generate_pair(destination, *, repository,
source_root, recipe)` creates a new private company source store for SH-IAM-007.
`AccessRemediationRecipe` accepts five exact `LifecycleSourceRef` values (also
exported as `AccessRemediationSourceRef`), an explicit producer label and selected
metadata SHA. Inputs are the same native review population, owner decisions,
review reconciliation, selected application version and supporting HR transfer
version. `input_at` bounds source availability; the remaining six timestamps
are explicit ordered local activity instants through `closeout_at`.

The two new branch IDs share the same retained inputs and removal decision.
One local permission resolver contains the exact removal mapping; the other
initially lacks that mapping. Execution changes an in-memory entitlement set
only when the mapping resolves the authorized request. A distinct scoped
operating reviewer probes that actual set, records the unresolved access,
requests correction, and repeats the check after correction. Earlier requests,
failed attempts and observations remain immutable. Repeated execution is
idempotent at the local authorization-state level. Twelve systems retain
22 native versions. No host permissions, network services or credentials are used.

Source native bytes, metadata, provenance and code/control assignment pins are
retained separately. The original source is reread before publication. New-only
private staged publication creates no audit, grants, collections or testing
credit. The maintained operator exposes this module as `access-remediation`;
selected-source V2/V3 routing is maintained separately.

This is a qualified continuation, not a rewrite of historical quarter reports.
Recorded omitted population members remain explicit unresolved limitations.
The source does not establish population completeness, whole-review closure,
professional assurance, real employment, deployment or corporate delegation.
AS-P007 and AS-P008 are scoped proposed owner/operating-review assignments;
AS-P009 remains the independent assurance contact with no assurance performed.
The explicit local requirement basis supplies the exercise timing; no corporate
remediation SLA is inferred.

Focused tests cover exact original preservation, state-driven probes, retained
failed history, unauthorized actor/subject/right rejection, nonredirectable
permission mappings, idempotent removal, invalid bindings and chronology,
private new output, and empty authority journals. Independent native-source
regressions and Engine collection tests are retained in adjacent test modules.
