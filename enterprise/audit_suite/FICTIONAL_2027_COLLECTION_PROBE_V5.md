# Disposable V5 source-to-collector probe

This probe requires the independently reviewed main-local V5 partial portfolio
and candidate routing bytes. It makes ordinary-byte private copies of both A/B
profiles' 40 components, then gives one narrowly scoped disposable grant and
collection to each of the **27 scenario components per side**. This includes
the reviewed fictional `govapp` and `sec005operated` company-native sources.
The result is **54 selected receipts**, each tracing a full native version
tuple through discovery, read and retained collection in a disposable copy.

The 13 pre-existing baseline components per side are copied but receive no
new grant or collection. The REC003 A/B snapshots each retain their historical
12 grants, 22 collections and 25 access events; exactly one new scoped probe
in each copy yields 13/23/26. Original company source roots, the active P1
pair and the reviewed V4 probe remain untouched.

This is a source-access diagnostic, not an engagement or a period evidence
population. Selected source event dates are fictional 2027; actual import
remains in 2026. `source_complete`, `fresh_audit_pair_created` and
`audit_task_credit` remain false. No clause, workpaper, task, Key or grade is
updated. The V5 source roster still has unresolved population, legal,
qualified-owner and external-response gates.
