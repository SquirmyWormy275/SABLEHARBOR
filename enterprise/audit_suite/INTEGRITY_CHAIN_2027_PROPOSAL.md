# Fictional 2027 nonpersonal integrity and transformation chain

This is a company-local, disposable test-copy source for one four-row nonpersonal work-unit fixture. It follows C3 in the reviewed data/record gap ledger. The input is the **corrected A-variant raw version 2** from the bounded 2026 DQ exercise, plus that exercise's exact reference and definition versions. Both Clean and Messy intentionally start from those same bytes. The A label identifies the older DQ fixture, not an A/B audit-side pairing. Later audit access journals changed the physical DQ SQLite bytes after its original independent verification. The producer therefore pins the independently reviewed post-journal source rebase, checks that the original 11 DQ business versions remain intact, excludes journal rows from company activity, and checks current source hash and inode stability. It creates a new private test-copy lineage per branch; it never edits the DQ original.

The independently declared *local test* denominator is exactly R1–R4 within the DQ definition's half-open UTC event window. AS-P014 is the proposed local data steward/operator; AS-P008 is a separate simulated security integrity checker. A predeclared test plan changes only R3 `units` from integer `9` to string `"9"` in each disposable copy. That is a simulated unauthorized alteration, not a real intrusion, human act or personal-data event. The source raw hash, altered hash, corrected hash, file inodes, exact native tuples and event/availability/import clocks remain separately available.
