# Disposable source-to-collector probe

`fictional_2027_collection_probe` exercises the real `FederatedCompanyStore`
read and collect boundary across all ten independently reviewed fictional 2027
company-source cohorts. It first re-verifies 178 native versions and the
partial 23-component/145-alias candidate profiles. It makes **ordinary-byte,
separate-inode** copies of each source database into a new private run; no
reviewed company original is opened for grant or collection mutation.

For each Clean/A and Messy/B route, the probe selects one exact native source
version, confirms read denial before an exact principal/engagement/system grant
on the disposable copy, then reads the original bytes and collects through the
federated adapter. It rechecks physical company, branch, system, record,
version, SHA-256, and business event, availability and real import clocks.
The run has 20 disposable collections total. Each cloned database has one
grant, one access event and one collection; all reviewed original source
identities and bytes are rechecked at the end.

The local principal and engagement IDs are diagnostic names only. No audit
engagement, PBC request, source-complete registry, workpaper, task, grade or
instructor Key is created. One collected version per cohort does not prove a
complete period population or any of the 283 unresolved discovery routes per
audit side. The active A/B pair keeps its frozen source binding and no credit.
