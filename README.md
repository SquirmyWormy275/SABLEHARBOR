# SABLE HARBOR

Sable Harbor is the canonical synthetic enterprise and reusable business-world sandbox for mining, natural-resources, enterprise-software, assurance, analytics, finance, governance, security, incident-response, and professional-training scenarios.

It is modeled as a company that would exist independently of any audit or benchmark. Business activity creates the systems, records, contracts, communications, controls, mistakes, and evidence; downstream tools consume deliberate, versioned scenario exports.

## Canon status

Decisions use three states:

- **LOCKED** — accepted canon;
- **PROVISIONAL** — recommended working canon pending review;
- **OPEN** — unresolved and not to be silently invented.
