# Definition of done — reconciled framework

This cleanup is complete when the accepted source model, GeoPackage, GeoJSON, QGIS project, atlas, source hashes, catalog, regression checks and PR dispositions agree. Completion of this integration does not claim completion of the original full geographic engineering program.

The [program closeout matrix](PROGRAM_CLOSEOUT_MATRIX.md) records every original numbered section and its remaining limits. Validation counts are generated in [the validation report](../reports/GEOSPATIAL_VALIDATION_REPORT.md); no frozen count is an acceptance criterion.

Original approved artwork and all main-branch industrial/finance source bytes must be unchanged. Current source drift is a build error. Historical source differences must be explicitly pinned and preserved, never mistaken for current drift.
