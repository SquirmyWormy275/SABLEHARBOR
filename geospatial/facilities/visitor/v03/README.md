# Sacramento visitor guide V03 — review draft

[Compare V02 and V03](review.html) · [PNG](artifacts/visitor-map-v03.png) · [PDF](artifacts/visitor-map-v03.pdf) · [SVG](artifacts/visitor-map-v03.svg)

The owner found V02 better but still sterile. V03 adds warm ivory building fills, buff paths, olive landscape tones, varied canopy symbols, subtle graphic shadows and softer typography. These are cartographic conventions, not material specifications, a solar study or new landscape design. Tree centers, building footprints, entrances, courts, parking and the arrival route remain sourced from the existing campus model.

V01, V02 and the four approved R01 originals are preserved. V03 remains a review draft pending exact-file visual acceptance. No production atlas entry or map ID has been allocated.

Sources and hashes: [SOURCE.json](SOURCE.json), [MANIFEST.json](MANIFEST.json). Review evidence: [QA.md](QA.md).

From the repository root, using the facilities Python environment:

python geospatial/facilities/visitor/v03/build.py
python geospatial/facilities/visitor/v03/validate.py
