# Sacramento visitor guide V02 — review draft

[Compare V01 and V02](review.html) · [PNG](artifacts/visitor-map-v02.png) · [PDF](artifacts/visitor-map-v02.pdf) · [SVG](artifacts/visitor-map-v02.svg)

Revision responding to the user's assessment that V01 looked too much like the early organization charts. White building silhouettes, quieter ground treatment, restored source parking markings and a compact directory replace V01's pastel blocks and repeated labels. All geometry and the arrival route remain sourced from the existing campus model.

V01 and the four approved R01 originals are preserved. V02 is a review draft, not an accepted replacement or production atlas entry. Production map ID allocation remains pending visual acceptance.

Sources and hashes: [SOURCE.json](SOURCE.json), [MANIFEST.json](MANIFEST.json). Review evidence: [QA.md](QA.md).

From the repository root, using the facilities Python environment:

```sh
python geospatial/facilities/visitor/v02/build.py
python geospatial/facilities/visitor/v02/validate.py
```
