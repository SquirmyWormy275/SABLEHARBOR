# Context snapshot archive

Original committed federal GeoJSON remains under `geospatial/reference/` and is linked by hash rather than copied. New September 11 official snapshots are preserved here: USGS elevation service and 81-point sample response/request; SACOG existing-bikeway metadata and regional response/request; original SacRT GTFS CSV members with feed metadata, archive/member hashes and request history. See ../CONTEXT.md and ../CONTEXT_SOURCES.json for licensing and interpretation.

DOWNLOAD_LOG.json records the successful GTFS ZIP retrieval and its original hash. Selected original CSV members are preserved; the temporary downloaded ZIP itself is deliberately omitted from Git. Direct SacRT portal HTML archival failed HTTP403; its published terms were verified with browser access and the exact official URL remains recorded. No absent document is presented as an archived success.
