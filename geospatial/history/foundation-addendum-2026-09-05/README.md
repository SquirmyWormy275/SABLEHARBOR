# September 5 geographic foundation and addendum packages

**Status: historical source packages.** These are exact recovery copies of two
dated distributions found in Downloads on 23 October 2026. They are available
from the [historical release](https://github.com/SquirmyWormy275/SABLEHARBOR/releases/tag/geospatial-foundation-addendum-historical-2026-09-05),
with every ZIP member and its hash in [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json).
The ZIPs are preserved byte for byte. The Download files were observed with an
October 19 workstation timestamp; that observation is not their authorship date.

| Original package | SHA-256 | Historical authority |
|---|---|---|
| `SABLE_HARBOR_Geospatial_Foundation_v0.1.0.zip` | `31d3aadb4ef241484cb62d5a9db51e64aa38f5458e2fd0286cc71cb297c245ee` | Engineered draft and conflict review. Its Red Wash map conflict, approximate study polygons, and intentionally empty site and rail layers describe the pre-addendum state. |

The foundation's internal manifest verifies 66 declared files; the addendum's
internal manifest verifies 252. Both complete ZIPs pass CRC, and the source
manifest records the remaining package members too. The two historical
GeoPackages inside them are different from the later tracked
`geospatial/master/sable_harbor_master_v0.1.gpkg`. The names alone do not make
the editions interchangeable. The source packages refer to baseline commit
`8d20e51a7cf0068729e3296840ccb5ba1ac1d7bd`; package integration is a
separate October 23 action.

Use the [current geospatial guide](../../README.md), [geographic evidence
release index](../../../docs/releases/GEOGRAPHIC_EVIDENCE_RELEASES.md), and
[current decisions](../../../docs/wiki/Locations.md) for later governing
geography. The accepted v1.5.0 package and later canon control the current
fictional geography. These older packages establish no survey, title,
construction or audit conclusion. Their own release notes retain each stage's
completeness limits. No old source package was rebuilt or corrected here.
