# Preserved Geo history

This directory is historical evidence, not current build authority. `rc3/` preserves prior explanatory records and the prior catalog. `superseded_mine_connector.geojson` and the historical Belle envelope retain rejected/superseded geography with explicit status.

`PR_SOURCE_INVENTORY.json` indexes every geographic file from PR #94 at `7471ba0f405e94e22813b03890d950f5a8aa1582` and PR #96 at `2849424fd25dd626d1ea2523add65a374f884457`. That includes their unique builders, source addendum, archives, maps and binaries. Branch deletion is not part of this cleanup. Old distributable ZIP bytes remain retrievable at those immutable commit URLs and are not replaced or duplicated in main.

The preserved rc3 journal file is inventoried as old build debris; it is deliberately excluded from the active integration. Its removal from current output is not loss of a source artifact. Historical metadata and counts describe their original checkpoint only.
