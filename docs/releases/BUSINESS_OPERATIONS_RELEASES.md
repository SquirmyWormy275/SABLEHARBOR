# Business operations releases

The [operating successor](../../enterprise/operations/README.md) deepens the accepted
[business-finance release](BUSINESS_FINANCE_RELEASES.md), preserving 2026 and
industrial financial boundaries. It adds causal Core operating histories, cash
obligation reconciliation, management revisions and scheduled control exercises.

Version 1.0.0 is undergoing implementation acceptance. Publication is complete only
when the clean main workflow passes and its immutable release is verified. The tag
is `business-operations-v1.0.0`; assets are
`sable-harbor-business-operations-v1.0.0.zip` and `SHA256SUMS.txt`.

The ZIP includes enterprise and seven unit CSV/SQLite packages, a prior-version
financial bridge, source identities, executed client handovers, control outcomes
and the reviewed workbook. Histories are synthetic conditional scenarios or retained
calibration. Failed/not-run controls, infeasible schedules and unpaid obligations
remain visible even when software acceptance passes.

Existing releases must not be overwritten. Later changes require a new version.
