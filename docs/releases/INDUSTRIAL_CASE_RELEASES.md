# Industrial case releases

The selected source package is [industrial v1.0.0](../../industrial/README.md). Its participant archive contains the complete selected dated company corpus, operating and financial datasets, maps, controlled PDFs and a combined SQLite database. Archives are distributed through GitHub Releases in accordance with the [delivery policy](../governance/REPOSITORY_DELIVERY_AND_PACKAGING_POLICY.md).

Release publication and the exact clean source-commit/checksum binding are recorded here after final acceptance. A working-tree preview is not a published release.
