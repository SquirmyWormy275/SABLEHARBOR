# Facility spatial releases

This successor adds offline 3D review, 86 independent architectural/context sheets, room schedules, access coordination and stable-ID revision comparison to the accepted facility atlas and planning workbench. Existing release bytes remain unchanged.

| Version | Source and status | Entry points |
| --- | --- | --- |

The complete package belongs in the [indexed GitHub Release](https://github.com/SquirmyWormy275/SABLEHARBOR/releases/tag/facility-spatial-v1.0.0), with a per-file manifest and SHA-256 checksum. Approved R01 originals and their explicitly permitted source ZIP remain embedded unchanged. Historical distribution ZIPs are omitted with an explicit exclusion inventory. Source revision and package manifest establish the exact delivered snapshot.

Spatial diagrams remain modelled studies. Geographic reference data has its own dates and precision; it does not assign the conceptual campus a real parcel. No changes to personnel, J2 authorization, actual occupancy or construction completion are implied.
