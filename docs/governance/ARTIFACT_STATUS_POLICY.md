# Artifact Status Policy

- **ACCEPTED_MAIN:** merged into `main` and explicitly accepted.
- **REVIEW_CANDIDATE:** proposed documentation, collateral, navigation, or publication work.
- **RELEASE_CANDIDATE:** implemented and testable but not independently accepted.
- **SOURCE_ONLY:** generator, schema, or source exists; named output is not published.
- **NOT_MATERIALIZED:** required standalone artifact does not yet exist.
- **OPEN:** unresolved corporate fact.
- **MODEL_PROPOSED / SCENARIO_INPUT / SYNTHETIC_INSTANCE:** quantitative model states.
- **HISTORICAL / SUPERSEDED:** preserved lineage, not current authority.

File presence, branch existence, a generated filename, or green CI does not by itself promote an artifact to accepted.
