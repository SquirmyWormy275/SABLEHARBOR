# Approved reference assessment preparation

The reference builder in `enterprise/ccf/assurance/reference.py` makes the approved corporate/Reno/Boise scope executable. It retains SOC 2 Security, Availability and Confidentiality and the HIPAA business-associate/subcontractor scenario, with design as of September 11, 2026 and Type 2 readiness as the future destination. An optional C5 selection exercises the extension path. No actual operating period or deployed evidence is asserted.

## Delivered preparation

- All 61 TSC and nine DC identifiers, original short topic labels, source hashes and downloaded-PDF page locators. The selected SOC categories plus description criteria comprise 47 records.
- Every Part 160/164 section and paragraph in the pinned GovInfo XML: 102 sections and 1,697 paragraph fingerprints. This includes definitions, enforcement context and sections omitted from the earlier discovery starter. Paragraph-order indices are not statutory paragraph citations.
- Candidate native mappings for the SOC topics, existing Security Rule attributes and additional business-associate/privacy/breach workpapers. Candidates remain unreviewed and include uncovered design work.
- 192 proposed implementation workpapers with native owner-role references, current control statements, operating triggers, expected evidence and local design tasks. Roles are not actual appointments.
- Baseline output: 447 requirement/boundary rows and 870 unexecuted attribute test plans. Counts include source/context and applicability work; they are not a count of active legal controls or failures.
- C5 extension: the 594 source subcriteria plus two internal discovery gates; eight continuity criteria now have source-anchored candidate workpapers for BIA, exercises and customer communication. The engine identifies candidate reuse of baseline controls while retaining source, mapping, scope and evidence blockers.
- CSV and JSON workpapers; source inventories; mapping-review queue; readable scope/readiness notes; the existing HTML/Excel assessment workbench; atomic new-directory exports and complete outer/inner re-performance.

## What the source work established

The public eCFR page reports Title 45 through September 10, 2026. The downloaded GovInfo Title 45 bulk XML has per-volume amendment dates; the relevant volume 2 reports August 28, 2026. The builder preserves that actual provenance. Local eCFR API retrieval returned HTTP 406 and the HTML route returned a non-rule page; neither was accepted as a source document. GovInfo XML was validated and the Part 160/164 section and paragraph population is reconciled to its pinned bytes at each reference build.

The [HHS legal-status notice](https://www.hhs.gov/hipaa/for-professionals/special-topics/reproductive-health/final-rule-fact-sheet/index.html) reports the court's vacatur of most of the 2024 reproductive-health rule and specifies affected notice provisions. A provision still printed in a retrieved XML is not automatically an enforceable requirement. The source population and scenario applicability therefore remain separate. The AICPA description PDF's exact identity with the current account-download variant remains unconfirmed; its named edition and our exact file hash are retained.

## Remaining acceptance work

This is a usable scoped preparation package, not a completed reviewed crosswalk or independent assessment. TSC points-of-focus/DC implementation guidance and engagement requirements need complete context review; HIPAA paragraphs need semantic, judicial-status and role-specific reconciliation. The source extraction alone does not close those reviews. Most C5 requirements still need objective decomposition, and full ISO sources remain missing.

Physical access and environmental protection, capacity management, authentication and encryption/key custody need more detailed local designs than broad existing native controls supply. BA contracts, minimum-necessary processing, breach notification, subcontractor flow-down and individual-rights support need actual service/data-flow/contract inputs. Implementation and test plans must then be executed against authorized operating evidence and independently reviewed. No reviews or test results were invented to make an unresolved delta appear supported.

The enterprise CCF remains the objective. This first bounded assessment validates the source/control/implementation/evidence/delta workflow; the private Atlas remains its reference companion. Existing generic starter and fictional demo behavior is unchanged.
