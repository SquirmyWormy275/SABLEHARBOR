# Navigation continuity foundation

Implemented bounded UX-01/CX-01/CX-02 helpers in `audit_suite_web/src/navigation.ts`. App integration is now implemented for the bounded behaviors below; broader contextual workspace acceptance remains pending. This does not supersede the broader UX/context workflow acceptance criteria.

The module uses only a normalized engagement returned by an authorized API request and the authenticated bootstrap viewer. `parseWorkspaceLink(search, engagement)` validates the engagement, destination and object collection; duplicate parameters, foreign engagement IDs, ambiguous record IDs, incorrect object destinations and unknown collections return the same unavailable result. No hidden collection, model or future event lookup occurs. `workspaceLink(location)` produces a relative link containing only identifiers; filters and draft text are excluded.

`createNavigationMemory()` retains bounded search/framework filters and scroll position in memory per destination. `activate(engagement, viewer)` clears cached context when the viewer, roles, engagement, permissions or scope change. Call it after every authorized fetch. `clear()` is required on logout, failed authorization, engagement-list navigation and explicit reset. It stores no records or drafts and does not provide durable saved workspaces. `orientation(engagement, viewer)` projects actual engagement title, boundaries, period, report type, roles, effective permissions and simulated time without inferring authority from a role label.

## Integration requirements and implemented foundation

1. After successful bootstrap and normalized engagement fetch, activate memory and resolve the current search string. Render generic unavailable content for a failed link. Do not retain the preceding engagement while a different engagement loads or after access failure.
2. Popstate with no engagement must set engagement to null and close active detail/forms/meeting state. This is implemented in the integrated load callback.
3. Before changing sections, save query/framework/actual scroll position. Restore the destination context after rendering. The integrated navigation helper now isolates and restores these values.
4. Object links should open a detail only from the already authorized collection identified by the resolved link. Revalidate a currently open detail after each refreshed state to handle removal or revoked visibility; never keep an old row object as authorization evidence.
5. Display projected orientation consistently in the workspace header. Global roles are informational; actual engagement permissions continue to govern actions. The integrated header now includes boundary/period orientation.
6. Explicitly clear detail, conversation draft, upload link and other engagement-bound state on switching engagements. This helper does not preserve or isolate those independent App state variables automatically.
