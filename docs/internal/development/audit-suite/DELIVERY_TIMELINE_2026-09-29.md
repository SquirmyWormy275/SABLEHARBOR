# Internal audit-rehearsal delivery timeline

**Planning baseline:** September 29, 2026. Target is a source-faithful,
fictional Clean/Messy CCF/audit rehearsal for the approved SOC 2
Security/Availability/Confidentiality and HIPAA scenario. This is an
engineering schedule, not a promised SOC 2 Type 2 report or claim of real
operating history.

Assume two to three focused builders, one dedicated independent reviewer,
prompt resolution of specific owner/qualified decisions, and no core data
model redesign. The reviewed task inventory is 409 procedures per branch;
283 per branch route through further company-native discovery or period
activity across 43 controls. The current 13-component pair is a technical
baseline with all tasks uncredited and cannot absorb new source systems.
The workload estimate is 20–40 focused builder-weeks before review rework;
the calendar below requires that capacity to be sustained. Intermittent
Codex sessions or a single builder do not imply the same elapsed dates.

finish if source development and review parallelize unusually well. February
