# Alexandria Control public/private scenario boundary

**Status:** repository boundary control
**Date:** September 3, 2026

Public `SABLEHARBOR` is the observable in-world surface. Private
`SABLEHARBOR-ALEXANDRIA-CONTROL` is the hidden-truth and evaluator control plane. The control-plane
name does not refer to the in-world Sable Harbor Alexandria institution.

Public artifacts may contain incomplete, messy, contradictory, or misleading evidence when those
qualities belong to in-world records. They must not identify hidden answers, seeded exception
truth, evaluator scoring, or expected-detection mappings. Alexandria Control may contain expected
NAILEX detections, a seeded exception registry, scoring rubrics, causal truth, hidden physical
state, actor knowledge, intervention truth, and leakage tests. A public file may name the control
plane and cite versions or checksums without disclosing private payloads.

| Scenario artifact | Repository |
|---|---|
| Public participant evidence | `SABLEHARBOR` |
| In-world institutional interpretation | `SABLEHARBOR` |
| Public-safe generator and schemas | `SABLEHARBOR` |
| Hidden physical truth | Alexandria Control |
| Causal truth | Alexandria Control |
| Actor epistemic state | Alexandria Control |
| Seeded exceptions | Alexandria Control |
| Expected NAILEX detections | Alexandria Control |
| Scoring rubrics | Alexandria Control |
| Leakage tests | Alexandria Control |
| Answer keys | Alexandria Control |

This boundary applies to all future audit scenarios, especially seeded control exceptions.
