# Northern Nevada Data Center — Layout and Space Program

**Status:** concept design basis; no completed building is asserted.

## Planning building

Target initial gross area: **12,000 sq ft** within the approved 10,000–15,000 sq ft range. The concept must be engineered, code-checked, and reconciled to actual site conditions before becoming construction drawings.

| Zone | Concept area | Function |
|---|---:|---|
| Data Hall A | 2,400 sf | conventional compute, storage, network rows |
| AI / High-Density Hall | 1,800 sf | liquid-ready accelerator rows, CDUs, high-density distribution |
| Network rooms A/B | 600 sf | physically separated carrier entrances/meet-me/edge |
| HSM / key room | 250 sf | separately controlled key hardware and recovery materials |
| NOC / incident room | 700 sf | operations, incident command, controlled monitoring |
| Secure receiving/quarantine | 800 sf | receiving, inspection, staging, custody |
| Spares / secure media | 550 sf | spares, removable media, destruction staging |
| Electrical / UPS / battery | 1,700 sf | initial modular critical-power equipment |
| Mechanical / cooling / CDU support | 1,200 sf | cooling distribution and controls |
| Security lobby/mantrap | 350 sf | identity/visitor control |
| Technician/support/MEP circulation | 1,650 sf | maintenance, sanitation, support, internal circulation |
| **Total** | **12,000 sf** | |

## Adjacency rules

Receiving must not open directly into a data hall. Network rooms A and B must be physically separated and fed from different property entrances. HSM/key room must not share the general NOC access group. AI Hall must adjoin mechanical/CDU support but remain separated from maintenance circulation. Electrical and generator/service areas require maintenance access without traversing data halls. Visitor paths terminate at the security boundary unless specifically escorted.

## Site layout

The 7.5-acre envelope reserves separate north/west and south/east telecom entrances, security setback, controlled vehicle gate, receiving/loading apron, electrical/substation/transformer area, generator/fuel yard, heat-rejection yard, emergency/fire access, parking, stormwater/drainage, and a future building/data-hall expansion pad.

## Construction truth

As of 2026-09-11 every room, building footprint, utility yard, and site arrangement in this program is **PROPOSED DESIGN**. The only completed facility milestone is planning-universe land acquisition. Drawings and maps must not render these spaces as built until corresponding construction-status events are accepted.
