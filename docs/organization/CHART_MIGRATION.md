# Organization chart migration

The September 9 cleanup replaces nine mixed organization SVGs and the former J2 high-level SVG/PNG with 39 shared chart families. Old active narrative diagrams now link to these views. Existing narrative URLs remain available.

The [v0.4.0 archive](history/v0.4.0/manifest.json) preserves the exact retired assets and registers from commit `7988f4740f39afa4a3db92e9efe1e0d737840d6d`. The [v0.3.0 archive](history/v0.3.0/manifest.json), original briefing package and pinned finance sources retain their bytes. The retired generators cannot recreate the previous current charts.

The numeric chart IDs are retired from the current register; unique semantic IDs identify successors. J2 work-product flows, the JAG role template, professional-assignment references, Cradle's operating boundary and dated lineage are separate process or historical references.

The [source-lock exceptions](SOURCE_LOCK_EXCEPTIONS.md) identify original organization documents whose exact bytes remain required by a released finance snapshot. Their older diagrams do not control the current company charts.

The complete chart book survived the interrupted upload as Git blob `729c0dda13aa213f63192ef9ddf9ef6ce61bda78`. Recovery preserved that exact vector publication and reconstructed its 202 display records from the saved source review, checked against every printed card. The current exporter uses the recovered PDF as the visual authoring master; it does not claim to recreate the lost layout-authoring program.
