## Interpretation rules

1. **A line is not automatically a reporting relationship.** Every chart states what its edges mean.
2. **Conceptual grouping is not legal ownership.** Pale Sun, Cradle, Willow, and ARU have different canonical roles, but their exact legal forms remain outside this chart package.
3. **Named leaders do not imply final titles.** The lore locks domains and responsibilities more strongly than titles or direct-report structures.
4. **OPEN nodes are intentional.** An unnamed ARU leader or an unformed Advisory home is more accurate than a polished invention.
5. **Historical units remain historical.** Evalon and Emberline appear in lineage maps but are not presented as standalone August 31, 2026 divisions.
6. **The repository controls the wiki.** Wiki pages may reproduce or summarize these diagrams, but they must link back to the versioned repository sources.

## Publication pattern

The root README carries only the compact operating-topology view. The full diagrams live here and can be reproduced on corresponding wiki pages. This keeps the README legible while preserving enough detail for readers who want the institutional architecture.

## Update sequence

When canon changes:

1. update the controlling canon document and decision register;
2. update the applicable organization map;
3. update `ORGANIZATION_MAP_REGISTER.json`;
4. update the README summary only when the top-level operating topology changes;
5. update the wiki after the repository change is accepted.

No diagram should be edited first and then treated as evidence that canon changed.
