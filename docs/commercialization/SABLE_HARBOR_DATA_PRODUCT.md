# Sable Harbor synthetic enterprise data product

Sable Harbor packages a fictional, multi-entity industrial enterprise for accounting/ERP developers, audit tooling, analytics vendors, AI evaluation teams, universities, consulting firms, incident-response platforms, and enterprise QA teams.

Proposed public packages are `finance-core`, `software-and-services`, `red-wash-operations`, `aru-bst-logistics`, `cradle-recovery`, `integrated-enterprise`, and `public-demo`. This repository does not implement or host an evaluator-only profile, hidden answer key, or private oracle. Any such material belongs outside the Sable Harbor public finance platform and remains subject to the Alexandria Control boundary.

The database is authoritative. Versioned CSV, SQLite, workbooks, manifests, and packaged query or
lineage examples are release surfaces. Raw `shfin query`, `statements`, and `explain-lineage` stdout
is explicitly labeled internal synthetic inspection output, not a release artifact. Every release
is synthetic and versioned and does not represent audited financial information.
