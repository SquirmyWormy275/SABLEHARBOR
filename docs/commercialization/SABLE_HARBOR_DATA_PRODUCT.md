# Sable Harbor synthetic enterprise data product

Sable Harbor packages a fictional, multi-entity industrial enterprise for accounting/ERP developers, audit tooling, analytics vendors, AI evaluation teams, universities, consulting firms, incident-response platforms, and enterprise QA teams.

Proposed packages are `finance-core`, `software-and-services`, `red-wash-operations`, `aru-bst-logistics`, `cradle-recovery`, `integrated-enterprise`, and `public-demo`. The `private-benchmark` package is an interface only; hidden truth is generated under ignored local storage.

The database is authoritative. CSV, SQLite, workbooks, manifests, queries, and lineage examples are release surfaces. Every release is synthetic and versioned and does not represent audited financial information.
