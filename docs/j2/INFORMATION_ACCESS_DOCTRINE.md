# INFORMATION ACCESS DOCTRINE

**Document ID:** `SH-J2-ACCESS-001` | **Version:** 1.0.0 | **State:** LOCKED

**Maximum useful visibility. Minimum necessary restriction.** Default access is open. Restriction is driven by information nature—not rank—including personal information, privilege, active M&A, and narrowly compartmented regulated/federal material.

Questions are common property and propagate wider than answers. Where lawful and appropriate, a user may see that relevant material exists but is restricted. Restriction creates named ownership, reason, challenge path, review, and duration/reconsideration. A failure to get knowledge to someone who needed it is investigated as an intelligence-system failure, not merely HR/IT administration. Security and IAM implement this doctrine; they do not define it.
