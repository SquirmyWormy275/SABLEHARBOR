# Reading glossary

[Start here](Start-Here.md) · [Open questions](Open-Questions.md) · [Wiki home](Home.md)

These short definitions explain how to read the archive. The [source and status guide](../reader/SOURCES_AND_FORMATS.md) and [maintainer authority rules](../../MAINTAINERS.md) provide the controlling detail.

| Term | Meaning in this archive |
|---|---|
| Canon | Accepted facts and institutional decisions within the fictional universe, subject to the stated authority order and later supersession. |
| LOCKED | Accepted canon. It does not mean that a real-world event occurred. |
| LOCKED DIRECTION | Accepted institutional direction with some implementation detail still able to mature. |
| LOCKED ARCHITECTURAL DIRECTION | Accepted architecture with runtime implementation still open. |
| PROVISIONAL | Accepted working direction, rather than final canon. |
| OPEN | An unresolved question that must not be filled in for completeness. |
| SUPERSEDED | Preserved history whose identified scope is now governed by a later record. |
| Reading edition | A published view of repository source text. The source's status, date and limits still apply. |
| Generated artifact | A representation produced from sources, such as a workbook, chart or catalog. Repetition and presentation do not create new authority. |
| Historical reconstruction | A later model or account of an earlier period, distinguishable from contemporaneous records. |
| Conditional forecast | An estimate under stated assumptions, rather than an observed result or funding commitment. |
| Billet | An authorized position. It is not automatically a named person, current employee or occupied seat. |
| Provenance | The traceable source and history of a record or claim. |
| Temporal integrity | Preserving the difference between when something happened, was recorded and became known. |
| Evidence gap | Missing support for a conclusion. It is different from a performed test that failed. |
