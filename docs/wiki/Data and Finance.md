# Data and Finance

The enterprise financial/data platform is currently a release candidate on [PR #9](https://github.com/SquirmyWormy275/SABLEHARBOR/pull/9), pinned by this audit at `1f294440a11e724e5f1bdcd3a7f59f7342169bfe`. It is not accepted or merged by the enterprise-portal workstream.

The branch contains shared accounting, commercial, mining, logistics, recovery, research, workforce, procurement, assets, debt, named queries, workbook generators, valuation, and release-source code. It models units through entity, segment, site, project, counterparty, scenario, and provenance dimensions.
