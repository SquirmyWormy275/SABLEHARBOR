# Wiki reading layer

[Open the company index](Home.md) · [Document library](Library.md) · [Use-case guide](../reader/USE_CASES.md)

The wiki's canonical presentation source lives here in ordinary Markdown. Seven business pages and the department/institution directory connect current source records, approved logos, existing organization charts, human-facing publications, financial packages, and facility plans. The generated library gives detailed file access without making the home page a file dump.

## Publication status

The [live GitHub Wiki](https://github.com/SquirmyWormy275/SABLEHARBOR/wiki) is initialized and published. Its first 56-page edition was accepted in September 2026; [PR #155](https://github.com/SquirmyWormy275/SABLEHARBOR/pull/155) expanded it to substantive business, department and history articles with 198 full supporting records. Earlier endpoint-unavailable reports are historical.

The remote `sable-harbor-wiki-manifest.json` is the current publication receipt. It identifies the accepted source revision, page hashes and reading inputs. The [publication freshness workflow](../../.github/workflows/wiki-freshness.yml) checks those inputs and the actual remote page bytes after main changes and daily. It reports stale content, independent edits or inspection errors; it does not publish automatically.

Publish a clean, refreshed accepted-main checkout with `make wiki-publish`, using existing local Git authentication. The optional [manual Actions workflow](../../.github/workflows/publish-wiki.yml) requires its own configured `WIKI_TOKEN`. No personal token needs to be copied to repository secrets for local publication.

The Wiki is a reading edition, not an independently edited source. Preserve the [Wiki policy](../governance/PUBLIC_REPOSITORY_AND_WIKI_POLICY.md). Historical page addresses remain as routes to the clearer titles, including links to their original sections.

## Maintenance and review

Business and department pages contain curated introductions, reading guidance, related subjects and explicit unknowns. Their in-depth source selections are composed at export time; controlling facts stay in the source records. The [library](Library.md) and `library/` pages are generated by `tools/documents/build_institutional_catalog.py`, alongside reader discovery tables in the existing institutional SQLite catalog. Do not hand-edit the generated inventories.

New visual design follows the owner's small-batch, exact-file review requirement. These pages reuse existing artwork and charts; they do not revise those assets. See the [reader delivery record](../reader/READER_DELIVERY.md) for scope and validation.

## Review locally

For a GitHub-like browser preview of the actual Markdown and existing images:

```bash
python -m pip install -r tools/documents/reader-preview-requirements.txt
python tools/documents/preview_reader.py
```

Open `http://127.0.0.1:8765/README.md` for repository Markdown. To review the composed reading edition and historical routes, use the export and browser commands in the [publication guide](../../tools/wiki/README.md). It serves only on the local machine and does not publish the wiki. The preview is an approximation; final GitHub layout may differ. Stop with Ctrl+C.

The [automated browser review](../../tools/ci/README.md#wiki-browser-review) checks department and business headers in light/dark themes and mobile/desktop viewports, preserving approved header hashes. Screenshots are review artifacts, not new visual sources.
