# Reporting method

All reports read posted journals or database domain records. Twenty-one named SQL queries cover ledger, source trace, software/customer, workforce/vendor, working capital, assets, Red Wash, ARU, Cradle, intercompany, debt, scenario, assumption, and coverage views.

The six workbook suites are generated from those database queries. Workbook formulas provide visible controls; no workbook is the sole source of a fact. Generated files are reopened independently and inspected for required tabs, broken references, external links, and practical size.

The current cash-flow workbook surface is a simplified indirect bridge. Full statement-of-equity, tax, and advanced consolidated cash-flow marts remain limited as documented.
