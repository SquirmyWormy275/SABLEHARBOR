# Legacy operating-model reconciliation

The v0.1 operating model is numerically useful but noncontrolling. Its 426 FTE, 34 contractors, $124.5M revenue, 70.3% recurring/product share, roughly 65% gross margin, $13.3M operating loss, $172.5M capital raised, $25M facility/$10M draw, 58 customers, and 104 sites are `LEGACY_CALIBRATION`.

## Alternatives

- **A — old total remains consolidated:** rejected as initial base because absorbing an underground uranium mine and established regional logistics operator inside the same scale would require unsupported displacement of CoreCo.
- **B — old model becomes CoreCo calibration:** selected. Reclassify obsolete Emberline/Pale Sun content, retain useful software/services calibration, then add Red Wash, Cradle, and ARU/BS&T. This is reversible and matches the canon change log.
- **C — full rebase:** retained as a scenario and eventual validation. It is preferable once industrial driver evidence is mature, but premature as the first implementation baseline.
